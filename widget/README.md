# Newsy iPhone widget (Scriptable)

A free Home Screen glance at the latest Newsy briefing.

## Setup

1. Install **Scriptable** from the App Store (free).
2. Open Scriptable → tap **+** to create a new script.
3. Paste the contents of `newsy-widget.js` (or the copy at the repo root).
4. Name the script **Newsy** and save.
5. On your Home Screen: long-press → **+** → search **Scriptable** → add a Small, Medium, or Large widget.
6. Long-press the widget → **Edit Widget**:
   - **Script:** Newsy
   - **When Interacting:** Run Script *(or Open URL if you prefer a one-tap jump to the site)*

That’s it. The widget refreshes about every 30 minutes, caches the last good fetch for offline use, and opens [Newsy](https://music-droid.github.io/Newsy/) when you tap it.

Run the script inside Scriptable anytime for a medium-size preview.
